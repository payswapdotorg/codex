# WO-014 — Learning and Governed Evolution

**Status:** MERGED (PR #16, 0d61744a)
**Depends on:** WO-010, WO-013
**Surface:** evidence-driven improvement candidates, replay/simulation, governed version evolution

## Objective

Use workflow execution evidence to propose improvements without ever silently mutating an installed or published workflow version.

## Required outcomes

- Generate improvement candidates for workflow definitions, capability bindings, recovery policies, dependency choices, and scheduling.
- Preserve provenance from evidence to candidate change.
- Validate candidates through replay, simulation, evaluation, and policy checks.
- Require explicit approval/publication to create a new immutable workflow version.
- Preserve rollback and lineage from predecessor to successor versions.

## Forbidden

- Online silent mutation of published workflow semantics.
- Treating model suggestions as authorization.
- Unbounded retention of sensitive credentials or external content.
- Learning logic that bypasses evaluation or control-plane authority.

## Acceptance

Execution evidence can produce traceable improvement candidates that are evaluated and, when approved, published as new immutable versions with complete lineage; existing versions remain unchanged.

## Evidence

Include candidate provenance, replay/simulation/evaluation results, approval path, lineage, rollback behavior, and exact SHA.
