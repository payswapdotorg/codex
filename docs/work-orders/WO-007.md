# WO-007 — Codex Computer Use Workflow Adapter

**Status:** MERGED (PR #7, ef1da6b6)
**Depends on:** WO-005
**Surface:** Codex-native Computer Use bridge and desktop workflow adapter

## Objective

Bind workflow execution to the existing Codex Computer Use capability without creating a parallel computer-use agent implementation.

## Required outcomes

- Discover and reuse the current Codex Computer Use feature/skill/runtime path.
- Provide capability lifecycle: declared → available → ready → authorized → bound → executing.
- Normalize screen/application/window observations and actions into workflow evidence.
- Support explicit session ownership, takeover, recovery, and policy boundaries.
- Detect missing `node_repl`/bridge/runtime provisioning or other readiness failures explicitly.
- Support workflows that mix Computer Use and Browser Use in the same graph/run.
- Permit compatible alternate desktop adapters only when semantic and policy requirements remain satisfied and record the fallback.

## Forbidden

- Reimplementing a second desktop-agent runtime.
- Desktop-specific implementation details in workflow semantic types.
- Credential leakage or policy bypass.

## Acceptance

A workflow step requiring desktop automation can execute using Codex Computer Use when available, records exact capability/binding/evidence identity, handles unavailable readiness explicitly, and composes with browser steps without a separate workflow engine.
