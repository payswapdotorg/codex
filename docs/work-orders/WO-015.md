# WO-015 — Additional Execution Environments

**Status:** MERGED (PR #14, 2042503a4)
**Depends on:** WO-005, WO-010
**Surface:** mobile, remote desktop, device, and additional environment adapters

## Objective

Extend the single Execution Plane to additional compatible environments without changing workflow semantics or creating environment-specific orchestration engines.

## Required outcomes

- Add execution adapters for mobile and/or remote desktop where a compatible Codex skill, plugin, connector, or bridge can satisfy the contract.
- Provide the same capability/resource/observation/action/result/recovery/takeover model as existing environments.
- Support future device/specialized environment registration without semantic redesign.
- Reuse existing Codex remote-control, skills, plugins, MCP, sessions, approvals, sandboxing, and tracing mechanisms where applicable.
- Make unsupported environments fail explicitly and diagnostically.

## Forbidden

- Environment-specific workflow semantics.
- A separate workflow engine for mobile/remote environments.
- Credential leakage or authorization bypass.
- Making one environment mandatory for universal workflows.

## Acceptance

At least one additional environment can execute an existing compatible workflow through the same execution contract, and introducing the adapter requires no workflow-semantic changes.

## Evidence

Include adapter contract conformance, mixed-environment run evidence, failure/readiness diagnostics, security/authorization checks, and exact SHA.
