# WO-013 — Evaluation and Differential Compatibility

**Status:** DISPATCHED (session 88cacce2, continuation nudge sent)
**Depends on:** WO-002, WO-010
**Surface:** reproducible evaluation, compatibility benchmarks, differential tests

## Objective

Create evidence-driven evaluation of Codex Universal behavior across models and workflow execution while protecting compatibility with upstream Codex.

## Required outcomes

- Build reproducible model/provider compatibility tests.
- Build workflow execution benchmarks covering environments, permissions, context sizes, long sessions, failures, recovery, and mixed-environment runs.
- Compare intentionally unchanged behavior against the upstream Codex baseline where applicable.
- Record outcome, safety, efficiency, recovery, latency/cost, and compatibility metrics.
- Keep evaluation fixtures deterministic and versioned.

## Forbidden

- Optimizing solely for synthetic benchmarks at the expense of architecture invariants.
- Changing runtime semantics to satisfy a test without an architecture/Work Order basis.
- Treating benchmark output as semantic authority.

## Acceptance

The project has reproducible tests that demonstrate provider/model substitution, workflow correctness, safety, recovery, and upstream compatibility with results tied to exact source revisions.

## Evidence

Provide benchmark definitions, fixture/revision identities, exact commands/results, compatibility deltas, and known gaps.
