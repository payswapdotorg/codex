# VWO-012 — Native Desktop GUI Task Coverage

**Status:** BLOCKED
**Depends on:** VWO-011, VWO-001, VWO-002
**Wave:** 4

## Objective

Validate that Codex Universal can automate ordinary computer GUI work rather than only browser DOM-style tasks.

## Required task families

Exercise real GUI interaction in the proving ground, including where supported:

- launch/focus/switch applications;
- windows, dialogs, menus, forms and settings;
- keyboard-only interaction;
- mouse click/drag/drop/scroll;
- copy/paste and clipboard workflows;
- file picker/open/save dialogs;
- filesystem navigation;
- create/rename/move/copy/delete files;
- document editing;
- spreadsheet/table manipulation;
- presentation/media manipulation where tooling exists;
- screenshots and visual confirmation;
- transient dialogs, notifications and focus changes;
- tasks requiring recovery after an unexpected GUI state.

At least three tasks must cross a GUI application and filesystem/terminal boundary.

## Acceptance

All scenarios must be taught through at least one of DEMONSTRATE, INSTRUCT and HYBRID across the worker pool. Results must include outcome evidence, environment binding, recovery behavior, and product friction. Failures must be classified as missing capability, binding/resource issue, workflow semantic defect, model issue, or environment-specific limitation.
