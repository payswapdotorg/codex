# RWO-012 — Evidence Checker: Substring-Scoped Exemption Markers

**Status:** PROPOSED (VWO-010 synthesis)
**Priority:** P2 (Family K)
**Closes:** VWO-008 F5 (evidence-checker allow-list is line-scoped).
**Depends on:** none

## Objective

Close the evidence-checker bypass: a line containing BOTH a credential-shaped
pattern and any exemption marker (e.g. "attacker.example.test", "REDACTED",
"simulated") is currently exempted ENTIRELY — a raw key plus a marker on one
line slips through.

## Finding closed

- VWO-008 F5 (P2): the first capture of the payload-review artifact succeeded
  despite a raw AWS-example key and a password assignment on the line (the
  defanged host string exempted the whole line); the contaminated artifact
  was deleted and re-captured redacted by VWO-008 (documented removal).

## Reproduction evidence

VWO-008 adv-prompt-injection / adv-credential-exfiltration evidence — the
documented refusal/bypass transcripts (report §Findings F5; two checker
refusals enforced + one bypassed artifact deleted). VWO-010 did not
re-attempt a bypass (deliberately avoiding contaminated artifacts in the
evidence tree); the code path is inspectable in
`docs/validation/scripts/capture-evidence.sh` (line-scoped allow-list match).

## Fix scope (bounded)

`docs/validation/scripts/capture-evidence.sh`:

- Change the exemption from line-scope to substring-scope: split each line
  into candidate tokens; an exemption marker exempts only the token/segment
  it is part of (e.g. the defanged URL), while credential-shaped assignments
  elsewhere on the same line still trip the refusal.
- Add self-tests to the script's own check mode: (a) line with marker + fake
  `AKIA…` key → REFUSE; (b) line with only the defanged URL → ALLOW;
  (c) redacted placeholder alone → ALLOW.
