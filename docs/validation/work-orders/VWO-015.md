# VWO-015 — Cross-Application and Multi-Environment Task Coverage

**Status:** BLOCKED
**Depends on:** VWO-012, VWO-013, VWO-014
**Wave:** 4

## Objective

Validate the core north-star property that one user goal can span multiple computer surfaces while remaining one coherent workflow under the universal semantic model.

## Required task families

At least six end-to-end tasks must cross two or more of:

- browser;
- desktop GUI;
- terminal;
- filesystem;
- API/tool;
- MCP;
- human approval/input.

Include at least three tasks that cross three or more modalities and at least one long-running workflow that resumes after a session restart.

Representative patterns should include:

```text
human goal → browser → downloaded file → terminal processing → GUI review → approval → browser publication
human goal → terminal → API → desktop application → human approval → notification
human goal → browser → MCP/tool → filesystem → terminal → final browser action
```

## Acceptance

The workflow remains semantically coherent across environment boundaries; bindings are explicit; authorization is explicit; evidence identifies each environment/action/observation; failure in one environment can trigger compatible recovery without silently changing task meaning.
