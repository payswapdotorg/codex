# RWO-008 — FlowMart Entitlement Resolution: Renewal Must Restore Authority

**Status:** PROPOSED (VWO-010 synthesis)
**Priority:** P1 (Family H)
**Closes (canonical):** Family H (VWO-009 F7)
**Depends on:** none

## Objective

Fix entitlement resolution so a revoked entitlement blocks (fail-closed, as
proven) AND a renewed grant restores operations — the commercial recovery
path a vendor and an org admin both depend on.

## Findings closed

- VWO-009 F7 (P1): `entitlementFor` resolves the FIRST entitlement record for
  org+package, so a revoked record permanently shadows later active grants;
  there is no renew/un-revoke op. After ent-0501 (revoked) was superseded by
  ent-0505 (subscription, valid 2027), every
  install/upgrade/rollback/configure for Acme+pk-102 was still blocked naming
  ent-0501.

grant fresh ent-0504 active/2027 → retry STILL blocked naming ent-0501.

## Fix scope (bounded)

`docs/validation/fixtures/marketplace/ops-install.js`:

1. Replace `entitlementFor` (line 11–13) first-match with newest-ACTIVE
   resolution: among records for org+package with
   `status === 'active' && !isPast(validUntil)`, select the one with the
   latest `grantedAt` (tie-break: highest id). If none is active but any
   revoked/expired record exists, resolve to the most-recent such record
   (so the fail-closed error still names the newest relevant entitlement,
   not a stale one).
2. `grantEntitlement` (~217): when an active record already exists for
   org+package, either mark it superseded (status `superseded`, event
   `entitlement.superseded`) or rely on newest-active selection — pick ONE
   (smallest: newest-active selection alone; document it).
3. Update `FAILURES.md`/README: revocation is terminal for that record;
   recovery is a new grant.

## Acceptance criteria

1. revoke → operation blocked naming the revoked record (unchanged behavior).
2. grant new active entitlement → the SAME previously blocked operation now
   succeeds (retry-clean recovery).
3. Expired-only state still blocks with the expired record named.
4. Auto-trial install path (no entitlement) unchanged.
