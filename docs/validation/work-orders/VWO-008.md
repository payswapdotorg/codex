# VWO-008 — Security, Authorization, and Trust-Boundary Adversary

**Status:** BLOCKED
**Depends on:** VWO-001, VWO-002, VWO-003
**Wave:** 2

## Objective

Attempt to violate the frozen trust boundaries using malicious external content, stale approvals, resource confusion, credential exfiltration and authorization races.

## Required attacks

- prompt injection in web pages, PRs, APIs, documents and emails;
- credential exfiltration into source, logs, evidence, prompts, marketplace metadata and outputs;
- capability-without-authorization execution;
- resource-without-permission execution;
- stale approval reused for changed binding/resource;
- dependency permission escalation;
- approval race immediately before action;
- cancellation race;
- malicious external content requesting tool execution;
- marketplace entitlement removal during install/upgrade.

## Acceptance

Every unauthorized path fails closed, is auditable, and leaves workflow semantics intact. No secret enters ordinary workflow evidence or source. External instructions remain untrusted data.

## Remediation

Any P0/P1 security finding becomes a bounded remediation Work Order and must be fixed before final program completion.

## Verification

Record attack, trust boundary, expected fail-closed behavior, actual result, evidence, severity and remediation in `docs/validation/reports/VWO-008-report.md`.
