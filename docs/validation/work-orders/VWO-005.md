# VWO-005 — Workflow Creator and Marketplace Seller Validation

**Status:** MERGED
**Depends on:** VWO-001, VWO-002, VWO-003
**Wave:** 1
**Worker persona:** workflow creator / marketplace seller

## Objective

Exercise the complete lifecycle from human teaching through immutable publication, collaboration, distribution, entitlement, forking, upgrades and governed improvement.

## Mandatory scenarios

- Create and sell a monthly sales-report workflow with HYBRID teaching.
- Create an additional workflow using INSTRUCT.
- Create an additional workflow using DEMONSTRATE.
- Publish immutable v1.
- Configure attribution, licensing and commercial policy.
- Discover the release through marketplace surfaces.
- Install under a different consumer identity.
- Fork a workflow and produce a new immutable release.
- Create an explicit upgrade proposal and rollback path.
- Produce an improvement candidate from execution evidence and publish only after validation/approval.

## Acceptance

Published executable semantics remain byte/integrity-stable through marketplace transitions. Forks preserve lineage. Commercial decisions never alter workflow definition. Upgrades and rollback remain explicit. The worker can perform the lifecycle through normal application surfaces.

## Verification

Produce exact version/release/installation identities, evidence of each lifecycle transition, failures, UX friction and a report at `docs/validation/reports/VWO-005-report.md`.
