# VWO-013 — Browser and Web-Application Task Coverage

**Status:** BLOCKED
**Depends on:** VWO-011, VWO-001, VWO-002
**Wave:** 4

## Objective

Validate broad browser automation across realistic web applications without reducing the workflow model to a browser-specific abstraction.

## Required task families

Cover:

- navigation and multi-page journeys;
- dynamic forms and validation;
- tables, search, filters and pagination;
- uploads/downloads;
- authentication and session renewal using approved capability bindings;
- multi-tab/window workflows;
- redirects and transient failures;
- rich editors and file attachments;
- browser-to-API handoffs;
- browser-to-terminal/file handoffs;
- visually ambiguous or changing UI states;
- cross-site or multi-application workflows where policy permits.

At least three scenarios must be authored from a human goal rather than a predefined action script.

## Acceptance

The same semantic workflow contract must remain valid across browser implementations supported by the current Codex capability bridge. Provider or browser implementation details must remain adapter-local. Evidence must distinguish model inference failures from browser capability/resource limitations.
