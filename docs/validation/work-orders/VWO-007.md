# VWO-007 — Persistence, Restart, Recovery, and Cancellation Adversary

**Status:** MERGED
**Depends on:** VWO-001, VWO-002, VWO-003
**Wave:** 2

## Objective

Attempt to break durable workflow authority through crashes, restarts, duplicate events, pause/resume, cancellation races and worker loss.

## Required attacks

Interrupt execution after instance creation, approval, binding, dispatch, observation, evidence persistence, step completion, failure, retry decision, pause, cancellation, trigger acceptance and trigger settlement.

Also test:

- duplicate webhook/schedule fires;
- concurrent trigger storms;
- process restart with Running instances;
- persisted resume position;
- paused workflow continuation;
- cancellation while action is pending;
- worker replacement;
- startup reconciliation;
- version pinning across restart.

## Acceptance

Every discovered duplicate/lost-transition/restart defect is reproducible. The test proves whether session loss preserves authority, execution position, idempotency, immutable version pinning and recovery evidence.

## Remediation

For each P0/P1, create a bounded remediation Work Order and drive it through implementation, verification and re-test. Do not merely report failures.

## Verification

Report exact interruption point, durable state before restart, state after restart, expected/actual outcome and remediation status in `docs/validation/reports/VWO-007-report.md`.
