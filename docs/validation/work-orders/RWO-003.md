## Fix scope (bounded)

`docs/validation/fixtures/marketplace/ops-install.js` — in
`configureInstall` (line ~100), `upgradeInstall` (~117), `rollbackInstall`
(~156), after resolving the install:

```js
const actorOrg = orgForUser(ctx.state, ctx.user.id);
if (actorOrg !== inst.orgId) {
  throw new R.AppError(403, 'permission_denied',
    `Install ${inst.id} belongs to ${orgName(ctx.state, inst.orgId)} — cross-tenant ${action} is denied.`,
    { installId: inst.id, installOrg: inst.orgId });
}
```

(marketplace_admin with a global permission may be exempted if the Tech Lead
wants an admin override — currently no op needs it; keep the guard absolute
for the smallest fix.)

3. Read path already org-scoped — unchanged.
