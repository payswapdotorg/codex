# VWO-016 — Unseen Human-Goal Generalization

**Status:** BLOCKED
**Depends on:** VWO-015
**Wave:** 4

## Objective

Test whether Codex Universal generalizes beyond the workflows and task scripts designed by the validation team.

This is the most important empirical test before the north-star verdict.

## Method

Create a pool of human-authored computer goals that are hidden from the implementation workers until execution time. The hidden tasks must not be supplied as workflow IR, action scripts, or prebuilt capability plans.

For each task:

1. Give the worker only the human goal and necessary ordinary application context.
2. Permit DEMONSTRATE, INSTRUCT, or HYBRID teaching according to the assigned test.
3. Require Codex Universal to infer the workflow and required capabilities/resources through its normal product path.
4. Run the resulting workflow on the original task.
5. Run it again with changed data/state where the goal remains semantically equivalent.
6. Introduce at least one controlled environmental perturbation.
7. Record whether the workflow succeeds, recovers, asks for legitimate human intervention, or fails.

## Held-out task diversity

The hidden pool must include tasks from multiple application families and must contain combinations not present in prior scenarios. At least one task should be intentionally designed by a tester unfamiliar with internal workflow contracts.

## Anti-cheating rules

- no peeking at a hidden task's expected action sequence;
- no hard-coded scenario IDs in workflow semantics;
- no direct internal workflow-store construction;
- no benchmark-specific planner/runtime;
- no treating an external model response as proof of execution success without environment evidence.

## Acceptance

Produce a generalization report showing:

- number and diversity of unseen goals;
- success rate by teaching mode;
- successful re-execution on changed state;
- adaptation/recovery rate;
- human-intervention rate and reason;
- failure classification;
- evidence that successful workflows were created through normal product pathways.

The report must explicitly distinguish **demonstrated breadth** from **unproven universal capability**.
