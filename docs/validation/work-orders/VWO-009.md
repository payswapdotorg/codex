# VWO-009 — Versioning, Marketplace, and Distribution Adversary

**Status:** MERGED
**Depends on:** VWO-001, VWO-002, VWO-003
**Wave:** 2

## Objective

Attempt to corrupt immutable workflow identity, fork lineage, entitlements, installation pins, upgrades or rollback semantics.

## Required attacks

- mutate published definition after publication;
- move/delete development branch after release;
- tamper dependency lock;
- install a moving ref as executable authority;
- fork without attribution/lineage;
- cross-owner/private-release discovery leakage;
- entitlement removal during installation;
- stale upgrade proposal;
- failed upgrade followed by rollback;
- attempt marketplace transition that alters executable semantics;
- install v2 while v1 is still running;
- downgrade a pinned instance implicitly.

## Acceptance

Published identities remain immutable, installations remain explicitly pinned, forks preserve lineage, access/entitlement gates cannot mutate executable content, and upgrades/rollback require explicit control-plane decisions.

## Verification

Record before/after version identities and semantic digests, access decisions, lineage, upgrade/rollback history and findings in `docs/validation/reports/VWO-009-report.md`.
