# VWO-011 — Universal Computer Task Taxonomy and Coverage Benchmark

**Status:** READY
**Depends on:** VWO-010
**Wave:** 4

## Objective

Turn the north-star claim — **automate anything a human can do on a computer** — into a measurable, repository-native coverage model without pretending that a finite test suite can mathematically prove the infinite task space.

Create a benchmark taxonomy that distinguishes environment modality, interaction modality, statefulness, application boundaries, data shape, human involvement, and failure/adaptation requirements.

## Required task dimensions

At minimum classify scenarios across:

- browser;
- desktop GUI;
- terminal/CLI;
- filesystem/document manipulation;
- API/tool/MCP;
- human-in-the-loop;
- mixed/multi-environment;
- single-application;
- cross-application;
- structured data;
- unstructured text;
- unstructured visual/media data;
- authentication/authorization;
- uploads/downloads;
- long-running/stateful tasks;
- parallel tasks;
- conditional/branching tasks;
- recovery/adaptation;
- destructive/irreversible operations;
- tasks with no predefined workflow supplied to the agent.

## Required benchmark artifacts

Create a versioned benchmark/catalog under `docs/validation/north-star/` containing:

- task taxonomy;
- scenario IDs;
- expected user goal;
- observable success criterion;
- required environments/capabilities;
- difficulty level;
- whether the task is scripted, human-authored, or held out as unseen;
- scoring rules;
- coverage matrix.

The benchmark must explicitly separate **architecture coverage**, **environment coverage**, **interaction coverage**, and **generalization coverage**.

## Forbidden

- Do not claim universal computer capability merely because existing scenarios pass.
- Do not narrow the north star to browser automation.
- Do not add a second workflow engine or benchmark-specific runtime.
- Do not hard-code a finite list as the definition of all possible computer tasks.

## Acceptance

A reviewer can inspect the catalog and determine exactly what portions of the computer-task space have been validated, what remains untested, and how new task families will be added without changing workflow semantics.
