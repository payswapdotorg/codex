# VWO-014 — Terminal, Filesystem, Data, and Developer-Tool Task Coverage

**Status:** BLOCKED
**Depends on:** VWO-011, VWO-001, VWO-002
**Wave:** 4

## Objective

Prove that Codex Universal can automate computer work that is naturally performed through terminals, files, scripts, developer tools, and structured local state.

## Required task families

Cover:

- shell commands and pipelines;
- environment/process inspection;
- file discovery and transformation;
- text and structured-data manipulation;
- archive/compression workflows;
- local service interaction;
- Git operations;
- build/test/lint workflows;
- log analysis;
- code editing and repository changes;
- CLI authentication through approved resource bindings;
- terminal-to-browser and terminal-to-GUI transitions;
- recovery from command failure, stale state, or process restart.

At least three tasks must use the terminal as one stage of a larger mixed-environment workflow.

## Acceptance

Execution must use the existing Codex terminal/sandbox/worktree primitives where appropriate. No validation-only shell orchestrator may become a second workflow runtime. Credentials and secrets must remain outside workflow source and ordinary evidence.
