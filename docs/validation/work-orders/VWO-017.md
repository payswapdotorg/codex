# VWO-017 — Universal Computer Automation North-Star Gate

**Status:** BLOCKED
**Depends on:** VWO-016, VWO-010
**Wave:** 4

## Objective

Produce the final empirical assessment of the north star:

> **Codex Universal should be capable of automating arbitrary computer-based work that a human can perform, subject to the capabilities, authorization, resources, and interfaces actually available in the execution environment.**

This Work Order does not claim a finite benchmark can mathematically prove an infinite task space. It determines whether the implemented architecture and observed validation evidence justify calling the system a general-purpose computer-work automation platform.

## Required synthesis

Reconcile:

- VWO-011 taxonomy/coverage matrix;
- VWO-012 native GUI coverage;
- VWO-013 browser coverage;
- VWO-014 terminal/files/developer-tool coverage;
- VWO-015 cross-application coverage;
- VWO-016 unseen human-goal generalization;
- all prior human-workflow/adversarial validation;
- all open and closed P0/P1/P2/P3 findings;
- environment/resource-provider limitations;
- explicit unsupported capabilities and why they are unsupported.

## Required verdict classes

The report must separately score:

1. semantic universality — whether one workflow model spans the tested environments;
2. interaction universality — whether computer actions beyond browser automation are supported;
3. environment universality — whether workflows can mix available environment modalities;
4. capability/resource universality — whether the system can discover/bind what the task requires without leaking provider semantics;
5. teaching universality — whether DEMONSTRATE, INSTRUCT and HYBRID can teach novel workflows;
6. execution reliability — success, recovery, restart and idempotency;
7. generalization — performance on held-out human goals;
8. product usability — whether ordinary users can accomplish this without architectural knowledge.

## Final gate

Do not mark the north star `PROVEN` merely because all scripted scenarios pass.

Use one of:

- `NORTH_STAR_SUPPORTED` — evidence demonstrates broad general-purpose computer-task automation with held-out generalization and no critical architecture/product blockers;
- `NORTH_STAR_PARTIALLY_SUPPORTED` — broad automation works, but evidence or environment coverage leaves material generality unproven;
- `NORTH_STAR_NOT_SUPPORTED` — critical modality, workflow, recovery, or generalization gaps prevent the claim.

The preferred result is `NORTH_STAR_SUPPORTED`, but the verdict must follow evidence rather than roadmap intent.
