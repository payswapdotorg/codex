# APP-003 — Fresh-Machine Install/Launch + Product Smoke Validation

**Status:** ACCEPTED — fresh-machine run 22 passed / 0 failed (evidence/app-003/run-20260915T185129Z); harness app003-fresh-env.sh committed
**Depends on:** APP-002
**Surface:** release artifact + user-facing application + validation harness

## Objective

Prove that an ordinary user can download and launch Codex Universal without source-level knowledge.

## Required validation

From a fresh environment outside the source checkout:

1. Download the release artifact from GitHub.
2. Verify the checksum.
3. Install/unpack using only published instructions.
4. Launch the application.
5. Start a session.
6. Reach workflow/teaching functionality.
7. Perform one representative real workflow action.
8. Close and relaunch.
9. Verify supported persisted state survives restart.
10. Exercise missing-credential/dependency error handling.

Capture exact version, SHA, environment identity, commands, expected/actual results, screenshots/logs where appropriate, and product friction.

## Acceptance

A clean-environment user-path smoke test passes without cloning the repository or directly calling internal workflow stores/protocol methods to simulate a missing user-facing path.
