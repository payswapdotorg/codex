# APP-002 — Reproducible Packaging + GitHub Download Artifact

**Status:** BLOCKED on APP-001
**Depends on:** APP-001
**Surface:** existing Codex build/release machinery

## Objective

Turn the accepted launch surface into a reproducible downloadable release artifact.

## Required work

- Use existing Codex release/build infrastructure where possible.
- Produce the smallest practical artifact for the primary supported OS/architecture.
- Produce an alternate supported artifact when existing machinery makes it practical.
- Record version, commit SHA, OS, architecture, checksum, build command, and launch command.
- Ensure no source checkout is required by the user.
- Ensure the artifact starts from a clean user workspace.
- Publish release metadata and exact user download/install instructions to GitHub.

## Forbidden

Do not introduce a new packaging framework or duplicate release logic without evidence that the existing machinery cannot satisfy the gate.

## Acceptance

A release artifact can be downloaded from GitHub, verified by checksum, installed/unpacked, and launched using the documented command from a clean environment.
